acme. · 使用说明
团队内网站点导航台。你的个人偏好只存在本机浏览器,不上传服务器。

键盘快捷键

/ 聚焦搜索框
Enter 在搜索框内直接打开第一个匹配站点
↑↓←→ 在卡片间移动焦点
Esc 清空搜索 / 关闭弹窗
? 打开本说明

功能

  • 📌 收藏置顶:悬停卡片点右上星标,收藏的站点排到顶部「★ 收藏」区。
  • ⚡ 常用直达:按你的点击次数自动置顶最常用的站点。
  • 最近访问:左侧栏按时间倒序列出最近打开的站点。
  • 账号 / 密码:卡片上点 账号 复制用户名,点 🔒 密码 复制密码(不明文显示)。
  • 二维码:悬停卡片点 QR 按钮,手机扫码打开(内网站点手机需先连飞连)。
  • 状态点:卡片右上角 绿=在线 / 红=离线,由你的浏览器实时探测。
  • 环境色块:阿里云 橙 · 内网 蓝 · SaaS 紫。
  • 主题 / 密度:顶栏右侧可切深浅色、紧凑模式。

访问前提 · 飞连

走内网 / VPC 的站点,必须先连上「飞连」客户端才能打开(否则打不开,状态点也会误报离线):
· 内网 蓝色块的站点(Nexus / Superset / ArgoCD / Jenkins,*.example.com),以及 Grafana(VPC 内网域名 …-vpc.grafana.aliyuncs.com);
· 阿里云控制台、GitHub、飞书文档走公网,连不连飞连都能开。

导入 / 导出(顶栏 ↓ / ↑)

你的收藏、点击次数、最近访问只保存在这台电脑的这个浏览器(localStorage),不同步、不上云。换电脑 / 换浏览器 / 清缓存就会丢。
导出 = 存成 nav-data.json 文件备份;导入 = 在另一台机器读回来。这是手动备份/迁移,不是自动同步。站点列表本身不受影响(那是统一维护的)。
